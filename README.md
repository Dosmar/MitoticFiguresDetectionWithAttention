\# Mitotic Image Classification in Glioma Using Attention-Enhanced CNNs 🧠



Welcome to the repository for my bachelor's thesis project! This project explores the use of lightweight, guided-attention mechanisms (using binary ROI masks) to classify mitotic figures in glioma tissue, rivaling the performance of heavy transformer models.
